# Next.js Templates and Examples

This directory contains production-ready templates and examples for common Next.js use cases.

## Available Templates

### Basic Templates
- `app-router-starter/` - Minimal Next.js 14+ App Router setup
- `pages-router-starter/` - Traditional Pages Router setup
- `full-stack-starter/` - Complete full-stack application template

### Feature Templates
- `api-routes-example/` - API routes with authentication and validation
- `auth-example/` - Authentication with NextAuth.js
- `blog-example/` - Blog with MDX and static generation
- `dashboard-example/` - Admin dashboard with real-time data

### Component Templates
- `ui-components/` - Reusable UI components with Tailwind CSS
- `form-templates/` - Form components with validation
- `layout-templates/` - Common layout patterns

### Integration Templates
- `database-integration/` - Database setup with Prisma/Drizzle
- `cms-integration/` - Headless CMS integration examples
- `payment-integration/` - Stripe payment processing

Each template includes:
- ✅ TypeScript configuration
- ✅ Tailwind CSS styling
- ✅ ESLint and Prettier setup
- ✅ Environment configuration
- ✅ Testing setup where applicable
- ✅ Deployment configuration
