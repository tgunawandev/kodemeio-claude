# CLAUDE.md — abcfood-claude-code

## Project Overview

**Purpose:** Collects all 26+ CLAUDE.md files from across the ABCFood ecosystem into a single browsable knowledge base with categorized index, gap analysis, and full-text search support.

**Stack:** Bash (POSIX-compatible), no external dependencies
**Location:** `/home/tgunawan/project/00-new-projects/abcfood/abcfood-claude-code/`

## Quick Reference

```bash
# Collect all CLAUDE.md files (idempotent, re-runnable)
./collect.sh

# Preview without making changes
./collect.sh --dry-run

# Show statistics only
./collect.sh --stats

# Search across all collected files
grep -r 'docker' docs/
grep -r 'keyword' docs/
grep 'keyword' ALL-CLAUDE.md
```

## Generated Files

All files in `docs/`, `INDEX.md`, `GAPS.md`, and `ALL-CLAUDE.md` are generated by `collect.sh`. They are tracked in git so the knowledge base is browsable without running the script.

To regenerate after upstream changes: `./collect.sh`

## Script Conventions

- Follows same conventions as `abcfood-mkdocs-material/scripts/sync-docs.sh`
- Same color codes (RED/GREEN/YELLOW/BLUE/CYAN), logging functions (log_info/log_success/log_warn/log_error/log_debug)
- Same exclusion patterns (node_modules, .venv, .git, etc.)
- Same header format with `================================================================` banners

## Important Notes

- The script uses `find` for auto-discovery — new CLAUDE.md files are picked up automatically
- Files are **copied** (not symlinked) for portability and grep compatibility
- The script excludes its own directory (`abcfood-claude-code`) from scanning
- `REPOS_BASE_PATH` env var overrides the default scan path

## Categories

Files are auto-categorized by project naming patterns:
- **ERP Systems:** `*odoo*`, `*frappe*`
- **Odoo Modules:** Projects under `src/private/`
- **Data Integration:** `*sync*`, `*airflow*`, `*dbt*`, `*clickhouse*`
- **Infrastructure:** `*hetzner*`, `*cloudflare*`, `*dokploy*`, `*monitoring*`, `*postgres*`, `*redis*`
- **Security & Identity:** `*authentik*`, `*1password*`
- **Collaboration:** `*plane*`, `*mattermost*`, `*jitsi*`
- **Archived:** Projects under `archived/`
