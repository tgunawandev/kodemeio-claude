## 📖 Quick Reference

### Common Commands
```bash
# Create new Next.js app
npx create-next-app@latest my-app --typescript --tailwind --eslint

# Development server
npm run dev

# Build for production
npm run build

# Type checking
npm run type-check

# Linting
npm run lint

# Testing
npm test
```

### Environment Setup
```bash
# .env.local
DATABASE_URL="postgresql://..."
NEXTAUTH_SECRET="your-secret"
NEXT_PUBLIC_API_URL="http://localhost:3000"
```
